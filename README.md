# Rhythm Sight-Reader (Bass & Rhythm Practice)

A zero-install, browser-based rhythm sight-reading trainer designed for bassists and rhythm players.

- **Live Demo (GitHub Pages)**: https://gnosia1104.github.io/rhythm-practice/

## Features
- **Print-quality SVG bass-clef rhythm generator** (Lv1 8th Basic / Lv2 Syncopation / Lv3 16th Notes, 2–32 bars, PDF print-ready)
- **Web Audio metronome & D2 bass demo playback**
- **Keyboard, Mobile Touch Pads & Audio Interface input** (multi-channel support, 35–1200 Hz bass bandpass detector, auto noise-floor calibration, latency compensation)
- **Detailed Grading**: timing accuracy (`±35ms` tight, early/late ms distribution), **rest violation detection**, **audio sustain & mute tracking**, and **Live / Reveal-at-End (Blind)** grading mode
- **Multilingual UI**: Korean (`한국어`), English, Japanese (`日本語`) with IME-independent shortcuts
